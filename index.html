Projects

Vanvitrak (2025)

An AI-powered land records verification platform integrating WebGIS, OCR, and satellite data. Includes an MCP-based chatbot for real-time land records and scheme eligibility, a blockchain verification workflow (SHA-256 hashing + Solidity smart contract validation), and an AI remote sensing pipeline for FRA claim polygons. Built with Next.js, Express.js, MongoDB, and Python.

Content Genie (2025)

An AI-powered content generation web app using the Google Gemini API, with a credit-based payment system, Clerk authentication, PostgreSQL via Drizzle ORM, and a Tailwind CSS interface. Built with Next.js, TypeScript, and PostgreSQL.

Enterprise Learning Management System (2025)

A full-stack LMS with course management, video streaming, and user dashboards. Integrated Clerk for authentication and Stripe for payments, deployed on AWS and Vercel using Docker. Built with Next.js, Node.js, AWS, and Docker.

Socioscrape - Social Media Forensic Analysis Platform (2024, SIH 2024)

Contributed frontend development and MySQL database design for a social media investigation platform for legal and forensic use cases, including interactive dashboards to visualize investigation data. Built with HTML, CSS, JavaScript, MySQL, Node.js, and Express.js.
