This is the source for my personal interactive 3D portfolio: an infinite hand-drawn corridor you walk through, with doors leading to my projects, background, skills, and contact info.

> [!NOTE]
> Enable hardware acceleration in your browser for smooth 60 FPS rendering.

## Rooms

- **Gallery** — my projects (Vanvitrak, Content Genie, Enterprise LMS, Socioscrape)
- **About** — background, education, achievements, and skills
- **Studio** — a full technical skills directory
- **Contact** — LinkedIn, GitHub, resume download, phone, and email

## Local Development

1. **Install dependencies** (Node.js v20+):
   ```bash
   npm install
   ```

2. **Start the dev server:**
   ```bash
   npm run dev
   ```

3. **Production build:**
   ```bash
   npm run build && npm run preview
   ```

## Tech Stack

React 19, React Three Fiber, Three.js, GSAP, Vite, SCSS.
